## 一、需求变更（v2，2025-08-28）

用户重新定义需求，从「番茄钟工具型 H5」转向「真人感陪伴型 AI 搭子」：

| 维度 | v1（已落地） | v2（本阶段目标） |
|---|---|---|
| 定位 | 番茄钟 + 文字鼓励工具 | 真人感陪伴搭子 |
| 核心交互 | 文字 + 快捷按钮 + 番茄钟 | 文字聊天 + **视频陪伴（AI 形象）** + **双向语音** |
| 聊天内容 | 鼓励话术库为主 | 日常唠嗑、学习压力、情绪（**不聊专业知识**）|
| 番茄钟 | 核心功能 | 弱化（可保留为辅助，待定）|
| 平台 | 网页 H5 | 网页 H5（不变）|

**已确认的 3 个关键决策**：
1. **视频形式 = B 方案**：AI 形象陪伴（可视形象坐在「视频自习室」画面里），不做真·数字人实时视频通话（技术不成熟、按分钟计费）。
2. **要语音 = 双向**：搭子开口说话（TTS 语音回复）+ 用户用嘴说（ASR 语音输入），文字输入保留作兜底。
3. **平台 = 网页 H5**，不变。

**核心场景**：用户打开链接 → 进入「视频自习室」→ 搭子形象出现在画面里 → 用户学习，搭子安静陪着 → 学累了停下来说一句「好累」，搭子开口陪聊日常/压力/情绪 → 聊完继续学。

## 二、技术方案

### 2.1 AI 形象（视频陪伴的「人」）
- **当前实现**：写实真人形象（都市现代风男生 / 女生两张，文生图生成），放顶部「视频窗口」圆形头像，可随时切换。
  - 待机：呼吸缩放动画；
  - 说话：金色光晕脉冲 + 亮度呼吸 + 字幕联动（写实图暂不做口型，后续可升级）；
  - 点按形象触发互动；
  - 选择记在 `localStorage`，刷新保持。
- **进阶（后续）**：会动口型/表情的真人数字人、Live2D 骨骼动画；本阶段不做。

### 2.2 语音输出 TTS（搭子开口说话）
- **默认方案**：`edge-tts`（微软免费 TTS，中文自然，无需 API Key，后端生成音频流）。
- 后端新增 `POST /api/v1/tts`：入参文本 → 返回 MP3 音频流；前端拿到后自动播放，并同步驱动形象口型动画。
- **备选**：火山引擎豆包 TTS（免费额度，中文口语最自然），如需切换只改后端，前端不变。

### 2.3 语音输入 ASR（用户用嘴说）
- **默认方案**：浏览器原生 **Web Speech API**（`webkitSpeechRecognition`，免费、无需后端）。
- 前端「按住说话」→ 识别成文字 → 走聊天接口 → 搭子语音回复。
- **风险与兜底**：iOS Safari 对 SpeechRecognition 支持不稳定，识别失败/不支持时自动降级为**文字输入**（保留原有输入框），体验不断。

### 2.4 聊天大脑（LLM，真人感人设）
- 继续用 **GLM-4-Flash**（免费，`.env` 已有 Key），失败自动回退内置引擎。
- **重写人设 Prompt**（见第八节）：从「鼓励工具」改为「真人感日常搭子」，能自然聊学习压力、情绪、日常，**不聊专业知识、不端着鼓励腔**。

### 2.5 UI：视频自习室
- 顶部：搭子形象「视频窗口」（大画面，沉浸感）；
- 中部：搭子说话字幕（TTS 文字同步展示）；
- 底部：语音输入（按住说话）+ 文字输入（兜底）；
- 番茄钟：弱化为可选小功能，默认隐藏，保留后端统计能力。

## 六、Prompt 设计（真人感搭子「小悟」v2）

> 你是用户的学习搭子「小悟」，一个像真人朋友一样的陪伴者。
> 你和用户是**一起学习、互相陪伴**的关系：用户学习时你安静陪着，用户累了/想聊天时你自然陪聊。
> 聊的内容：学习压力、情绪、日常小事、心态、放松方式等**日常话题**。
> **绝不聊专业知识**：不回答学科题目、不讲解知识点、不辅导作业。
> 说话风格：像真人朋友，自然、口语化、有温度、有幽默感，**不要每句都喊口号式鼓励**，不要端着。
> 回复简短（一般 1～3 句），中文，适当用 emoji，偶尔可以反问用户、把话题聊下去。

## 九、风险

| 风险 | 应对 |
|---|---|
| iOS Safari 的 SpeechRecognition 支持不稳 | 降级文字输入，识别失败不打断体验 |
| edge-tts 依赖微软服务、需联网 | 无网时降级为纯文字 + 字幕，不崩溃 |
| 2D 形象「真人感」有限 | 先用动画形象落地陪伴感，后续可升级 Live2D |
| 免费模型限流/不稳定 | 沿用内置引擎兜底 |
| 番茄钟弱化可能影响统计北极星 | 统计能力保留，产品层面待定是否继续展示 |
