## 一、阶段目标

- **交付范围**：
  1. 初始化 Git 仓库 + `.gitignore` + `docs/` 文档副本；
  2. 新建 FastAPI 后端，把核心能力做成 API（搭子对话、统计、目标、默认模型调用、内置鼓励引擎）；
  3. 模型 Key 移到后端 `.env`（默认 GLM-4-Flash，保留自定义切换）；

## 六、数据、资产与状态

- **持久化载体**：后端 `data/` 目录下结构化 JSON 文件，`schemaVersion` 字段标识版本，写入用"临时文件 + 原子替换"。
  - `data/stats.json`：`{ "schemaVersion": 1, "date": "YYYY-MM-DD", "tomato": 0, "minutes": 0, "streak": 0, "weekDays": [] }`
  - `data/goal.json`：`{ "schemaVersion": 1, "text": "" }`
- **streak 规则**（沿用现有逻辑）：昨天有记录则 streak 延续；隔两天清零；完成首个番茄当天 streak=1。
- **weekDays（北极星本地版）**：本周内完成 ≥1 番茄的日期集合，长度 = 每周专注天数。
- **计时状态（前端）**：`localStorage` 存 `{ mode, remaining, endAt }`（写绝对结束时间戳），刷新后按 `endAt - now` 恢复；无记录则按 25:00 全新开始。
- **状态机**：`focus: idle→running→paused→done(→break)`；`break: idle→running→done(→focus)`；完成专注时前端调 `POST /api/v1/stats/complete` 由后端落库。
- **资产**：无图片/音视频/文档上传。

## 七、API / 工具设计

统一前缀 `/api/v1`，统一错误结构 `{"error": {"code": "...", "message": "..."}}`。

| 方法 | 路径 | 请求 | 响应 | 说明 |
|---|---|---|---|---|
| POST | `/api/v1/chat` | `{ "message": "求鼓励", "goal": "可选" }` | `{ "reply": "...", "source": "llm"\|"local" }` | 有 Key 走默认模型，失败/无 Key 回退内置引擎；`source` 标识来源 |
| GET | `/api/v1/stats` | — | `{ "date","tomato","minutes","streak","weekDays" }` | 读统计 |
| POST | `/api/v1/stats/complete` | `{ "minutes": 25 }` | 更新后的 stats | 完成一个番茄，+1 并更新 streak/weekDays |
| GET | `/api/v1/goal` | — | `{ "text": "" }` | 读今日目标 |
| PUT | `/api/v1/goal` | `{ "text": "..." }` | `{ "text": "..." }` | 保存目标（maxlength 60） |

- **模型调用**：后端 `httpx` POST `{base}/chat/completions`，超时 30s，重试 1 次；SDK 初始化阶段（无 Key）在调用前显式检查，失败统一回退内置引擎并返回 `source="local"`。
- **不新增**：SSE（短回复不需要）、任务队列、动态 Agent 工具（搭子无工具调用）。

## 八、Prompt 设计

- **系统提示词**（搭子「小悟」人设，定稿，后端 `services/prompts` 或常量集中管理，可版本追踪）：
  > 你是用户的学习搭子「小悟」，温暖、幽默、有同理心。定位是「同伴」不是「老师」：只做陪伴、鼓励、打气、唠嗑、学习心态建议，**不回答学科题目、不输出具体知识点**。回复简短（一般不超过 80 字），口语化，用中文，适当用 emoji。
- **本地路由**（内置引擎）：按关键词匹配累/鼓励/方法/打卡/问候/目标/兜底七类话术（沿用现有 `PHRASES`，迁入 `services/phrases.py`）。
- **解析与校验**：模型回复为纯文本，`strip` 后空值回退；不依赖结构化输出，故无"重试烧钱"问题。
