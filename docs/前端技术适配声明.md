- **主要用户**：学生 / 自学人群（个人使用）
- **主要终端**：移动 Web 优先，兼顾桌面浏览器
- **新项目或已有项目**：已有项目——MVP 前端已落地（单文件 H5，原生 HTML/CSS/JS）
- **本阶段业务目标**：MVP 前端已完成；本声明记录技术适配决策，并为后续「正式前端」迁移提供依据

## 3. 技术选择

- **框架与版本**：原生 HTML + CSS + 原生 JS（单文件，无构建、无依赖）——**偏离 Next.js 默认**，见第 6 节
- **样式**：CSS 变量（语义色板）+ 手写原子类
- **数据请求**：集中在 `api()` 封装 + `apiChat / apiEncourage / apiStats / apiComplete` 等业务函数
- **流式通信**：无（均为短请求，回复简短，不需要 SSE）
- **表单方案**：原生 `input`
- **测试方案**：后端 pytest（40 passed）；前端无自动化，以 `node --check` 做语法校验 + 真实浏览器人工验收
- **部署环境**：FastAPI `StaticFiles` 挂载同源静态文件（无 CORS、无独立前端部署）

## 4. Agent 状态

本产品无「长任务 / 工作流 / 产物生成」，核心是「对话 + 番茄钟」，状态模型按需简化：

- **对话**：`busy` 标志（防重复发送）+ `talking` 标志（说话中）+ 失败兜底文案
- **番茄钟**：`idle → running → paused → done` 四态，`localStorage["sb_timer"]` 存绝对结束时间戳，刷新恢复
- **取消 / 打断**：`stopSpeech()` 打断当前语音 + 字幕；`speechGen` 代际标记避免旧请求覆盖新回复
- **主动搭话**：60 秒无交互触发 `idle` 场景话术

## 5. 页面与产物

- **核心页面**：单文件三 Tab——💬 陪伴（视频形象 + 聊天）、🍅 专注（番茄钟）、👤 我的（统计 + 日历）
- **核心业务闭环**：打开 → 陪聊（文字/语音）→ 番茄专注 → 完成打卡 → 我的页看记录
- **产物类型**：语音（MP3，经 `blob → ObjectURL` 播放）、形象图（静态 JPEG）
- **响应式目标**：390px 移动端为主，桌面自适应

## 6. 偏离本手册的地方

| 偏离项 | 原因 | 影响 | 恢复条件 |
|---|---|---|---|
| 未用 Next.js + TypeScript，用单文件原生 JS | MVP 快速验证；功能已完整落地；避免为符合手册而重构 | 无 lint/typecheck/build/E2E 工程化；可维护性随功能增加而下降 | 进入真实用户 / 上线阶段时迁移 Next.js + TS |
| 无组件化、状态库 | 页面少、状态简单，单文件尚可维护 | 后续加功能（徽章/目标/周报）会变拥挤 | 功能继续增长或需多人协作时 |
| 前端无自动化测试 | MVP 阶段以人工验收 + 后端测试为主 | 回归风险靠人工 | 迁移正式前端时补 Vitest + Playwright |
| 语音输入用浏览器 Web Speech API（非 MediaRecorder → 后端 ASR） | 免费、零后端、MVP 够用 | iOS/非 HTTPS 环境受限 | 需要更高识别质量或全端兼容时，切 MediaRecorder + 后端 ASR |
