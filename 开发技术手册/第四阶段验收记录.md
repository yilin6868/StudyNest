## 二、8 个工具验收

| 工具 | 权限结果 | 是否会直接改变产品状态 |
|---|---|---:|
| `get_today_goal` | 只读，自动允许 | 否 |
| `set_today_goal` | 必须有后端确认的明确用户意图 | 是，保存本人今日目标 |
| `get_focus_state` | 只读，自动允许 | 否 |
| `request_start_focus` | 返回“需要用户确认” | 否，只生成确认动作 |
| `request_pause_focus` | 必须有明确用户意图 | 否，只生成确认动作 |
| `complete_focus` | 仅可信系统来源和匹配的计时证据 | 是，且沿用数据库幂等规则 |
| `get_study_stats` | 只读，自动允许 | 否 |
| `update_preference` | 必须有后端确认的明确用户意图 | 是，只保存白名单偏好 |

工具参数不接受用户 ID。所有数据操作使用登录后端放入可信上下文的用户 ID，因此模型不能通过参数查看或修改其他人的数据。

## 三、安全边界验收

| 检查项 | 结果 |
|---|---|
| 未注册工具 | 拒绝，返回固定安全错误 |
| 非法或多余参数 | 在执行处理器前拒绝 |
| 模型伪造 `userConfirmed` | 作为多余字段拒绝，不能获得权限 |
| 开始、暂停专注 | 只返回待确认动作，不控制浏览器计时器 |
| Agent 直接结算专注 | 拒绝 |
| 可信结算重复提交 | 数据库只记账一次 |
| 同一请求重复执行副作用 | 第二次拒绝，不自动重试 |
| 工具超时或内部异常 | 回滚并返回固定错误，不暴露数据库异常或密钥 |
| 状态观察内容 | 不包含用户名、密码、Token、邀请码、数据库主键和连接信息 |
| 工具能力范围 | 没有 Shell、文件读写、任意网络或外部插件 |

## 五、隔离与范围检查

- 自动测试只使用临时 SQLite、匿名测试账号和测试邀请码。
- 自动测试强制关闭真实模型调用，并在浏览器层阻断 TTS 外部请求。
- 没有连接 PostgreSQL 生产库，没有读取或迁移真实用户数据。
- 没有执行生产部署。
- 没有修改正式 `/api/v1/chat` 行为。
- 没有实现 P1-B 的 Agent 多轮循环或前端动作执行器。
- 没有实现 P1-C 的长期记忆、情绪安全流程或持久化 Agent 轨迹。
