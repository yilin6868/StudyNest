## 四、重点安全结论

- 会话 ID 只负责定位，所有读取、续聊和删除都再次核对当前登录用户。
- 模型不能静默写入长期记忆，也不能更改程序从用户原话绑定的类别和内容。
- 临时情绪、危机、医疗和常见敏感隐私被拒绝写入长期记忆。
- `crisis` 输入在 Agent Runtime 之前截断，回复为固定文本，动作始终为空。
- 危机原文不进入消息表、会话摘要、长期记忆和 Agent 事件。
- Agent 轨迹只接受固定事件类型和脱敏元数据；记录失败不回滚已成功的业务操作。
- 前端对未知协议、未知展示模式和未知动作继续采用拒绝策略。

## 五、尚未执行的验收

### 5.1 人工产品与安全验收

状态：待验。

尚未由产品方完整体验会话恢复、双账号隔离、三类记忆管理和安全回复文案。固定安全回复、危机规则覆盖与误判案例还需要具备相应能力的专业人员复核。自动测试通过不代表已经可以处理所有现实风险。

### 5.2 真实模型冒烟

状态：待验。

本次没有获得使用真实模型的单独授权，因此没有访问真实 LLM。后续需在隔离测试账号中验证多轮理解、摘要、记忆工具选择和输出安全防护。

### 5.3 PostgreSQL 实库与发布

状态：待验，继续阻止生产发布。

当前只验证了 SQLite 迁移。正式发布前还必须在隔离 PostgreSQL 中验证迁移、回滚、约束、索引和并发更新，并复核生产密钥和数据保留配置。
